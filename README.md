# assist

A dashboard and CLI for running coding agents (Claude Code, Codex or pi) across your repos, from a shared backlog through to verified commits and pull requests.

</picture>

Read the [documentation](https://staffordwilliams.com/assist/) to get started.

## Install

```bash
npm install -g @staff0rd/assist
assist sync
```

Then follow [Getting started](https://staffordwilliams.com/assist/getting-started/). Update with `assist update`.
